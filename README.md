# Перевод конфигурации в YAML · Вариант № 17

Программа читает один документ в UTF-8 из стандартного ввода.
Документ состоит из объявлений констант и одного итогового значения.
Результат записывается в файл YAML. Имена в учебном языке состоят только
из латинских букв и различают регистр. В коде Python используется snake_case.

## Подготовка и запуск

Проверено на Python 3.12. Из корня проекта в Linux или macOS выполните:

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m compileall -q src
./run.sh -o result.yaml < examples/library.conf
python3 -m unittest discover -s tests -v
```

Команда compileall компилирует исходники в байт-код. Её можно пропустить
при обычном запуске. Распаковщики без поддержки прав доступа позволяют
запускать сценарий через `sh run.sh`. Прямой запуск:

```sh
python3 src/main.py --output result.yaml < examples/studio.conf
```

Обязательный ключ `-o` (полная форма `--output`) задаёт выходной файл.
Родительский каталог должен существовать. Ключ `-h` выводит справку.
Переводчик возвращает 0 при успехе, 1 при ошибке документа или файла.
Ошибки аргументов дают код 2. Ошибки разбора содержат строку и столбец.
При ошибке языка существующий выходной файл сохраняется.

## Правила языка

| Запись | Значение |
| --- | --- |
| `0x2a`, `0XFF` | Целое шестнадцатеричное число |
| `[[текст]]` | Строка до ближайшего `]]`, включая пробелы и переводы строк |
| `{key = value,}` | Словарь. Допускаются вложенность, пустой словарь и завершающая запятая |
| `set name = value;` | Связать имя со значением для последующих обращений |
| `name` | Получить значение ранее объявленной константы |
| `\|+ a b\|` | Сложить два целых числа |
| `\|print a\|` | Напечатать значение в stderr и вернуть его |

Запись print выбрана по аналогии с префиксным сложением из задания.
Внутри выражений допускаются десятичные операнды, как в примере
`|+ имя 1|` из условия. Вне выражений числовой литерал задаётся
в шестнадцатеричной форме. Повторное объявление связывает имя с новым
значением. Повтор ключа в одном словаре вызывает ошибку.

## Примеры

1. Библиотека. Вход: `set stock = 0x1a; {title = [[Атлас мира]], copies = |+ stock 1|}`.
   В YAML получаются название «Атлас мира» и количество экземпляров 27.
2. Теплица. Команда `./run.sh -o greenhouse.yaml < examples/greenhouse.conf`
   создаёт словарь зоны «Север» с вложенным порогом датчика 19.
3. Студия. Команда `./run.sh -o studio.yaml < examples/studio.conf`
   выводит 8 в stderr и записывает 8 в поле channels словаря session.

## Функции и зависимости

- `src/language.py` — `build_grammar()` строит грамматику pyparsing.
  `evaluate(node, source, constants, output)` вычисляет узел с учётом
  известных констант и направляет вывод print в переданный поток.
  `translate(source, output)` разбирает весь документ, обрабатывает
  объявления по порядку и сериализует итог через PyYAML.
- `src/main.py` — `main()` читает ввод, открывает указанный выходной
  файл после успешного перевода и возвращает код завершения.
- `tests/test_language.py` — `run_cli()` запускает отдельный процесс,
  `check_document()` сравнивает YAML и потоки вывода, `check_invalid()`
  проверяет ошибку и сохранность файла. Функции `test_examples()`,
  `test_values()`, `test_invalid()` проверяют примеры, значения и ошибки.
  `load_tests()` регистрирует их в unittest.
